# Productivity Hub 0.2.0 — Cài đặt & đưa vào dùng

Bộ cài: `apps/desktop/release/PPH-Setup-0.2.0.exe` (tạo bằng `npm run desktop:dist`).

---

## 1. Cài đặt

1. Chạy `PPH-Setup-0.2.0.exe`.
   - Windows SmartScreen có thể báo "Windows protected your PC" vì bộ cài chưa ký số → **More info → Run anyway**.
2. Chọn thư mục cài (mặc định `%LOCALAPPDATA%\Programs\Personal Productivity Hub`) → Install.
3. Mở **Productivity Hub** từ Desktop/Start Menu. Icon xuất hiện ở khay hệ thống (góc phải thanh taskbar).
   - Đóng cửa sổ = thu xuống khay, app vẫn chạy nền. Muốn thoát hẳn: chuột phải icon khay → **Thoát**.

**Đã cài 0.1.0?** Chạy bộ cài 0.2.0 đè lên, dữ liệu giữ nguyên (`%APPDATA%\Personal Productivity Hub\data`); app tự nâng cấp database khi mở.

> Nếu app báo **"Cổng 4317 đang được ứng dụng khác sử dụng"**: tắt bản dev (`npm run dev`) hoặc server thử nghiệm đang chạy rồi mở lại.

## 2. Thiết lập ban đầu (5 phút)

Trong app → **Cài đặt**:
- [ ] **Múi giờ** đúng (mặc định Asia/Ho_Chi_Minh).
- [ ] **Giờ làm việc**: khai báo khung giờ bạn thực sự dùng để làm việc cá nhân cho từng thứ (ví dụ T2–T6 19:00–23:00, T7–CN 08:00–22:00). Gợi ý lịch chỉ xếp vào các khung này.
- [ ] Xem lại **XP, Pool, Penalty** (mặc định "bộ cân bằng" — để nguyên nếu chưa chắc).
- [ ] Khay hệ thống → bật **Khởi động cùng Windows** nếu muốn Hub luôn chạy (nên bật để đánh giá phạt, nhắc deadline, đồng bộ lịch chạy đúng giờ).

Rồi tạo **Goal** đầu tiên (Mục tiêu → Tạo) và vài **Task** gắn vào.

## 3. Kết nối Google Calendar (15 phút, làm một lần)

### 3.1 Tạo OAuth client trên Google Cloud
1. Mở <https://console.cloud.google.com/> bằng tài khoản Google có lịch bạn dùng.
2. Tạo project mới (ví dụ "Productivity Hub").
3. **APIs & Services → Library** → tìm **Google Calendar API** → **Enable**.
4. **APIs & Services → OAuth consent screen**:
   - User type: **External** → Create.
   - App name: "Productivity Hub", User support email + Developer email: email của bạn → Save.
   - Scopes: có thể bỏ qua (app tự xin quyền lịch khi đăng nhập).
   - **Publishing status → Publish app → "In production"**. (Để ở Testing thì Google bắt đăng nhập lại mỗi 7 ngày.)
5. **APIs & Services → Credentials → Create credentials → OAuth client ID**:
   - Application type: **Desktop app**, tên tùy ý → Create.
   - Copy **Client ID** và **Client secret**.

### 3.2 Kết nối trong Hub
1. Hub → **Cài đặt → Google Calendar** → dán Client ID + Client secret → Lưu.
2. Bấm **Kết nối** → trình duyệt mở trang đăng nhập Google.
   - Màn hình "Google hasn't verified this app" là bình thường với app cá nhân → **Advanced → Go to Productivity Hub (unsafe)** → cho phép truy cập lịch.
3. Trạng thái chuyển **Đang hoạt động**. Chọn các lịch dùng để tính **giờ bận** (mặc định lịch chính; bỏ lịch Sinh nhật/Ngày lễ nếu có).

### 3.3 Kiểm tra
- [ ] Mở một Task → **Phiên làm việc** → thêm phiên ngày mai 19:00–20:00 → trong ≤ 1 phút Event xuất hiện trên Google Calendar (lịch chính).
- [ ] Trên Google Calendar (điện thoại/web) kéo Event đó sang 21:00 → trong ≤ 5 phút (hoặc bấm **Đồng bộ ngay**) phiên trong Hub thành 21:00–22:00.
- [ ] Bấm **Gợi ý lịch** cho một Task chưa xếp → gợi ý tránh các giờ bận trên Google.
- [ ] Hoàn thành Task → Event trên Google có dấu "✓ ".

## 4. Nối app học tiếng Nhật (10 phút)

1. Hub → **Tích hợp → Đăng ký app**:
   - Tên: `Japanese Learning App`
   - app_id: **`japanese-learning-app`** (phải đúng chuỗi này — app tiếng Nhật gửi kèm trong mọi sự kiện).
2. Trong app vừa tạo → **Tạo key** → **copy ngay** (key chỉ hiển thị một lần).
3. **Quy tắc ánh xạ** → Thêm (gợi ý):

   | Loại sự kiện | Goal | Cách tính | Thời lượng mặc định |
   |---|---|---|---|
   | `vocabulary.learned` | Goal học từ vựng (ví dụ "Học 1000 từ") | PER_UNIT · `count` × 1 | 20 phút |
   | `learning.session.completed` | Goal tiếng Nhật chung | PER_UNIT · `duration_minutes` × 0,5 | (lấy từ sự kiện) |
   | `lesson.completed` | Goal tiếng Nhật chung | FIXED 30 | 30 phút |

4. Đưa cho Agent của app tiếng Nhật:
   - Tài liệu `docs/integration/2026-11-07-japanese-app-integration.md`
   - `HUB_URL = http://127.0.0.1:4317`
   - `HUB_API_KEY = <key vừa copy>`
5. Kiểm tra:
   - [ ] Học vài từ trong app tiếng Nhật → Hub → **Tích hợp → Lịch sử sự kiện** có sự kiện **PROCESSED**.
   - [ ] Goal tương ứng tăng Contribution; XP/Pool tăng; Streak hôm nay được tính.
   - [ ] Sự kiện **IGNORED** = chưa có quy tắc cho loại đó → thêm quy tắc rồi bấm **Áp dụng cho các sự kiện IGNORED**.
   - [ ] Sự kiện **FAILED** → mở chi tiết xem lý do → **Thử lại**.

## 5. Xử lý sự cố nhanh

| Hiện tượng | Cách xử lý |
|---|---|
| Google Calendar trạng thái **Lỗi – Cần kết nối lại** | Cài đặt → Google Calendar → Kết nối lại (token bị thu hồi/hết hạn) |
| Event không lên lịch | Xem badge đồng bộ trên phiên (PENDING/ERROR); kiểm tra mạng; bấm Đồng bộ ngay |
| App tiếng Nhật nhận **401** | Key sai hoặc đã thu hồi → tạo key mới, cập nhật bên app |
| App tiếng Nhật nhận **403** | `source.app_id` khác `japanese-learning-app` |
| Không mở được app, báo cổng bận | Tắt tiến trình khác đang dùng cổng 4317 |
| Cần xem log | Khay → Mở thư mục dữ liệu → thư mục `logs/hub.log` cạnh `data/` |

## 6. Dùng thử 1 tuần & ghi phản hồi

Mỗi khi thấy vướng, ghi 1 dòng: **màn hình / bạn muốn làm gì / chuyện gì xảy ra**. Sau 1 tuần gửi lại danh sách — đó là đầu vào cho đợt cải tiến tiếp theo (thay vì đoán tính năng).
